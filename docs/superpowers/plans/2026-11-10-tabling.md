# Tabling for `select` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A declared user functor's calls are memoised per query in
variant tables and evaluated to completion by component, so a
recursive `select` terminates on a cyclic graph with the complete
answer set, and a construct that reads an incomplete table as closed
is refused.

**Architecture:** A `tabled` slot on the functor and one installation
helper pick a tabled entry closure over the existing dispatcher. The
entry keys the call by variant, keeps per-query tables in a special
bound at the two query roots, evaluates with an add-answer
continuation, tracks each table's lowest open dependency to complete
components early, iterates a component's leader in rounds until no
answer is added, and refuses a read-as-closed construct whose floor
sits above an open dependency. Nothing changes for untabled functors.

**Tech Stack:** Common Lisp (SBCL verified; `#+ecl`/`#+ccl` arms kept),
FiveAM, the `tests/perf/prolog-bench.lisp` harness.

**Spec:** `docs/superpowers/specs/2026-11-10-tabling-design.md`
(D1 to D9 below refer to its sections).

## Review Focus

1. A tabled predicate called with a **compound first argument holding
   an unbound variable** (`(p (f ?x))`): key numbering must walk into
   conses; two such calls share a table and consumers get fresh copies.
   Pinned in `tb-nonground-answers` (task 3).
2. A **cut inside a tabled clause** in a program where a later round
   would skip a clause: the table keeps earlier-round answers (D5), the
   query returns them, and no error. Pinned in
   `tb-cut-and-once-across-a-table` (task 5).
3. A **non-local exit through a follower's evaluation** followed by a
   plain call in the same round: no half table survives
   (`tb-abandoned-tables-are-dropped`, task 5).
4. A **nested component under a floor** (`not` over an independent
   recursive tabled predicate inside another recursive one): completes
   under the floor and is not refused (`tb-negation-is-stratified-or-
   refused`, task 4).
5. **Two threads** each running a tabled query on the same functor:
   tables never cross (`tb-tables-are-per-thread`, task 3).
